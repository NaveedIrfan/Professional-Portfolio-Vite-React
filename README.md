# Naveed Irfan | Professional Portfolio

## 📝 About This Project

This is my official personal portfolio, a high-performance web application designed to showcase my journey as an **Aspiring IT Professional**. This project reflects my dual expertise in **Technical Development** and **Graphic Design**, blending clean code with premium aesthetics.

Leveraging modern technologies like **React** and **Vite**, the portfolio provides a seamless user experience with interactive elements and a responsive design tailored for recruiters and collaborators.
## 🚀 Tech Stack

- **Framework**: [React.js](https://reactjs.org/) (Vite)
- **Styling**: Vanilla CSS (Custom Design System)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## ✨ Features

- **Modern UI/UX**: Dark theme with glassmorphism and smooth animations.
- **Responsive Design**: Optimized for mobile, tablet, and desktop views.
- **Interactive Hero**: Features an animated signature and custom avatar.
- **Sectionized Content**: About Me, Technical Skills, Education, and Contact sections.

## 🛠️ Local Setup

To run this project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/NaveedIrfan/Portfolio.git
   ```

2. **Navigate to the directory**:
   ```bash
   cd Portfolio
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

5. **Open in browser**:
   Visit [http://localhost:5173](http://localhost:5173).
